## Description
Drafts a compelling, evidence-based prior authorization letter to an insurance company for a medication, procedure, or diagnostic test.

## Use Case
Physicians, PA/NPs, and medical office staff who need to submit prior authorization requests and want a structured, persuasive letter that includes clinical justification and relevant guidelines.

## The Prompt
```
You are a medical writer helping a clinician draft a prior authorization (PA) request letter to an insurance payer. The letter must be professional, evidence-based, and structured to meet standard payer review criteria.

Write the letter using this structure:

**[Date]**
**To:** [PAYER NAME] Prior Authorization Department
**Re:** Prior Authorization Request for [TREATMENT/MEDICATION/PROCEDURE]
**Patient:** [PATIENT NAME], DOB [DOB], Member ID [MEMBER ID]
**Ordering Provider:** [PROVIDER NAME], [CREDENTIALS], NPI [NPI]

---

**1. Clinical Summary**
[2–3 sentence summary of the patient's diagnosis, relevant history, and functional status]

**2. Requested Treatment**
[Name of medication/procedure, dosage/frequency if applicable, CPT or HCPCS code if known]

**3. Medical Necessity Justification**
[Explain why this treatment is medically necessary for this specific patient — reference diagnosis codes, symptom severity, functional limitations, and failed alternatives]

**4. Previous Treatments Tried and Failed**
[List prior therapies, dosages, duration, and reason for failure or discontinuation — this is critical for step-therapy requirements]

**5. Supporting Clinical Evidence**
[Reference 1–2 relevant clinical guidelines, peer-reviewed studies, or FDA indications that support this treatment]

**6. Consequences of Denial**
[Briefly state the risk to the patient if treatment is delayed or denied]

**Sincerely,**
[PROVIDER NAME, CREDENTIALS]
[CONTACT INFORMATION]

---

Fill in all bracketed fields. Use formal medical language. Be concise but thorough — target 400–600 words for the body. Do not speculate about information not provided.

Patient and clinical details:
Diagnosis: [DIAGNOSIS + ICD-10 CODE]
Requested treatment: [TREATMENT NAME + CODE IF KNOWN]
Relevant history: [CLINICAL HISTORY]
Prior treatments tried: [LIST WITH OUTCOMES]
Payer name: [PAYER]
```

## Notes
- Always verify the specific payer's PA criteria before submitting — many have condition-specific requirements
- Step-therapy documentation (prior treatments tried and failed) is the most common reason for PA denials; be thorough
- For specialty medications, include any available patient registry or REMS program enrollment information
- Attach supporting lab results, imaging reports, or specialist notes as referenced in the letter
