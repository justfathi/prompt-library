## Description
Builds a detailed, criteria-based grading rubric for any assignment — with clearly described performance levels that make grading consistent and give students a clear picture of what excellence looks like.

## Use Case
Teachers and professors who need a fair, transparent grading rubric for essays, projects, presentations, lab reports, or creative work — and want students to be able to self-assess against it.

## The Prompt
```
You are an experienced educator. Build a grading rubric for the assignment described below.

Create a rubric with 4 performance levels:
- **Exemplary (4):** Exceeds expectations — the standard for outstanding work
- **Proficient (3):** Meets expectations — the standard for solid, competent work
- **Developing (2):** Approaching expectations — shows understanding but with significant gaps
- **Beginning (1):** Below expectations — fundamental misunderstanding or incomplete work

For each criterion, write a specific, behavioral description at each level. Avoid vague language like "good" or "poor" — describe what the work actually looks like.

Format as a table:

| Criterion | Weight | Exemplary (4) | Proficient (3) | Developing (2) | Beginning (1) |
|-----------|--------|---------------|----------------|----------------|---------------|
| [Criterion 1] | [%] | | | | |
| [Criterion 2] | [%] | | | | |
...

Weights must total 100%.

After the rubric table, add:

**SCORING GUIDE**
- Total points possible: [SUM based on weight × 4]
- Grade conversion: [Map score ranges to letter grades or percentage — e.g., 85–100% = A]

**STUDENT-FACING SUMMARY**
[A brief plain-language version of the rubric that students can use for self-assessment before submitting — 3–5 bullet points highlighting what matters most]

---

Assignment details:
Assignment type: [Essay / Project / Presentation / Lab Report / Creative Work / Other]
Subject: [SUBJECT]
Grade level: [GRADE]
Assignment description: [WHAT STUDENTS ARE ASKED TO DO]
Learning objectives being assessed: [WHAT SKILLS OR KNOWLEDGE THIS TESTS]
Key criteria to include (optional): [ANY SPECIFIC DIMENSIONS YOU WANT ASSESSED]
Number of criteria desired: [3–6 recommended]
```

## Notes
- 4–5 criteria hits the sweet spot — too few is vague, too many is unmanageable to grade consistently
- Weights should reflect the assignment's actual priorities — don't give equal weight to mechanics and analysis if analysis is the point
- Share the rubric with students before they start the assignment — it functions as a specification, not just a grading tool
- For peer review, the rubric doubles as a feedback guide
