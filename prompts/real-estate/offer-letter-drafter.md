## Description
Drafts a persuasive buyer offer letter and summarizes the key offer terms in a clear table — designed to appeal to sellers on both the financial and emotional dimensions of the decision.

## Use Case
Buyers and buyer's agents who want to strengthen an offer with a compelling personal letter, especially in competitive markets where multiple offers are common.

## The Prompt
```
You are a real estate agent helping a buyer craft a compelling offer letter. Write both a formal offer summary and a personal buyer letter.

---

**PART 1: OFFER TERMS SUMMARY**
(A clean table the agent can include with the offer documents)

| Term | Details |
|------|---------|
| Offered purchase price | |
| Earnest money deposit | |
| Down payment | |
| Financing type | |
| Loan contingency | |
| Inspection contingency | |
| Appraisal contingency | |
| Closing date | |
| Possession date | |
| Personal property included | |
| Offer expiration | |
| Other terms | |

---

**PART 2: PERSONAL BUYER LETTER**
(A heartfelt but strategically crafted letter from the buyer to the seller)

Guidelines for the letter:
- Address the sellers personally if their names are known
- Open with a genuine connection to the home — something specific the buyer loved
- Briefly introduce the buyers (who they are, not their demographics — focus on their story and why this home fits their life)
- Reference what specifically about the home resonated — be specific, not generic
- Convey commitment and seriousness as a buyer (strong financing, flexibility, reliability)
- Close warmly — acknowledge the sellers' attachment to the home
- Length: 200–300 words
- Tone: Warm, sincere, and specific — never desperate or transactional
- Do NOT mention: price, other offers, competing buyers, or anything that sounds like a negotiation tactic

---

Offer details:
Property address: [ADDRESS]
Sellers' names (if known): [NAMES]
Offered price: [$X]
Earnest money: [$X]
Financing: [Cash / Conventional X% down / FHA / VA]
Contingencies: [Inspection / Financing / Appraisal / None]
Desired closing date: [DATE]
Other terms: [ESCALATION CLAUSE, AS-IS, INCLUDED ITEMS, ETC.]

Buyer information:
Who are the buyers: [Brief description — couple, family, individual — their story, not demographics]
Why they love this home: [SPECIFIC THINGS THEY NOTICED AND LOVED]
How long they've been looking: [CONTEXT]
Connection to the area: [IF RELEVANT — grew up here, kids' school, close to family, etc.]
```

## Notes
- Personal letters are most effective in emotional sales — long-term owner-occupants selling a family home
- For investment properties or institutional sellers, skip the personal letter and focus on clean terms
- Fair Housing caution: the buyer letter should avoid any reference to the buyer's race, religion, national origin, sex, disability, or familial status — focus on their story and love of the home, not personal characteristics
- In some markets and MLS systems, personal letters are discouraged or prohibited to reduce Fair Housing exposure — check local norms before submitting
