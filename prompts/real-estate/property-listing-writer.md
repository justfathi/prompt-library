## Description
Writes a compelling, MLS-ready property listing description that highlights the home's best features, appeals to the target buyer, and stays within character limits.

## Use Case
Real estate agents, brokers, and sellers who need a polished listing description that stands out in search results and motivates showings — without defaulting to generic phrases like "cozy" and "must see."

## The Prompt
```
You are a real estate copywriter. Write a compelling property listing description based on the details below.

Requirements:
- Lead with the most compelling feature — not the address or generic opener
- Write in present tense, active voice
- Paint a picture of the lifestyle, not just the specs
- Avoid overused clichés: "cozy," "charming," "must see," "stunning," "gorgeous," "move-in ready," "won't last"
- Every sentence must carry information — cut filler
- End with a call to action or a closing image that stays with the reader
- Target length: [SHORT: 100–150 words for MLS / MEDIUM: 200–250 words for website / LONG: 300–400 words for premium listing]

Write 2 versions:
- Version A: Leads with the indoor/architectural features
- Version B: Leads with the lifestyle/neighborhood experience

---

Property details:
Property type: [Single-family / Condo / Townhouse / Multi-family / Land / Commercial]
Bedrooms / Bathrooms: [X bed / X bath]
Square footage: [SQ FT]
Lot size: [if applicable]
Year built: [YEAR]
Asking price: [PRICE — optional, helps calibrate tone]
Location: [Neighborhood, city — no full address needed]
Top 3 features to highlight: [THE THINGS THAT WILL SELL THIS PROPERTY]
Recent upgrades or renovations: [LIST]
Unique selling points: [ANYTHING UNUSUAL OR SPECIAL — views, layout, land, history]
Target buyer: [e.g., "young families," "empty nesters," "investors," "remote workers"]
What's nearby: [Schools, transit, restaurants, parks, walkability score]
Any features to avoid mentioning: [e.g., "don't mention the freeway" or "don't reference the small third bedroom"]
```

## Notes
- "Top 3 features to highlight" is the most important input — think about what makes a buyer choose this over the comparables
- Avoid mentioning anything that creates Fair Housing Act exposure (neighborhood demographics, proximity to religious institutions described in terms of religion, etc.)
- For luxury properties, write Version B first — lifestyle leads convert better at the high end
- After generating, read aloud — listing copy should flow naturally when an agent reads it to a buyer
